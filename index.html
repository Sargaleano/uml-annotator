    UML Annotator
    What is this?

    A local-only, browser-based tool for semantically annotating handwritten UML class diagram images for research datasets. No server, no cloud, no authentication — just open index.html and annotate.

    Quick Start
    1. Open index.html in Chrome, Firefox or Edge.
    2. Select a role (Annotator or Verifier) and enter a username, then click Begin.
    3. Click Load Images to select your diagram images from disk.
    4. For each image, fill in the Description, add Classes (with attributes and methods), and define Relationships between classes.
    5. Click Mark Complete when an image is fully annotated.
    6. Use Validate at any time to check for schema errors.
    7. Click Export JSON (or press Ctrl+S) to save your work as annotations.json.
    Roles
    • Annotator — creates and edits semantic annotations.
    • Verifier — reviews completed annotations and marks them as verified. Only verifiers see the Verifier Controls panel.
    Relationship Types

    Allowed values (strict enum, no free text):

    association inheritance aggregation composition dependency realization

    Autosave & Recovery

    Work is autosaved to localStorage every ~2 seconds. If the browser closes unexpectedly, the draft recovery dialog appears on next launch (or after Sign Out). Images must be reloaded after a recovery — annotation data is fully preserved.

    Import / Export

    The dataset is a single annotations.json file keyed by image filename. Use Import JSON to merge an existing dataset, and Export JSON to save. Multiple annotators can work on separate exports and merge them via Import.
